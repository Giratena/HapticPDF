Quick start

  • Click 📂 Import to load a .funscript
  • Select a chapter in the sidebar
  • Click the graph to add a keyframe
  • Drag a point to reposition it
  • Right-click a point to delete it
  • Drag chapter edge handles on the timeline to resize
  • Press ▶ Play to preview
  • Click 💾 Export to download

Integration

  • <script type="module" src="funscript/funscript-editor.js">
  • <funscript-editor filename="out.funscript">
  • JS load: editor.importScript(obj)
  • JS read: editor.exportScript()
  • Event: funscript-change — every edit
  • Event: funscript-export — on Export click
  • Fully isolated Shadow DOM — no CSS conflicts

Funscript format

  • actions[].at — ms from global start
  • actions[].pos — 0 (out) → 100 (in)
  • Supports both StartTimeMilis and startTime string on import
  • Export produces both formats for compatibility
